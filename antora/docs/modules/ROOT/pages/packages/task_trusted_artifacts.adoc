= Trusted Artifacts Conventions Package

Policies to verify that a Tekton task definition conforms to the expected conventions required for using Trusted Artifacts.

== Package Name

* `trusted_artifacts`

[#trusted_artifacts__workspace]
=== link:#trusted_artifacts__workspace[Workspace]

Tasks that implement the Trusted Artifacts pattern should not allow general purpose workspaces to share data. Instead, data should be passed around via Trusted Artifacts. Workspaces used for other purposes, e.g. provide auth credentials, are allowed. Use the rule data key `allowed_trusted_artifacts_workspaces` to specify which workspace names are allowed. By default this value is empty which effectively disallows any workspace.

* Rule type: [rule-type-indicator failure]#FAILURE#
* FAILURE message: `General purpose workspace %q is not allowed`
* Code: `trusted_artifacts.workspace`
* Effective from: `2024-07-07T00:00:00Z`
* https://github.com/conforma/policy/blob/{page-origin-refhash}/policy/task/trusted_artifacts/trusted_artifacts.rego#L47[Source, window="_blank"]

[#trusted_artifacts__workspaces_format]
=== link:#trusted_artifacts__workspaces_format[Workspaces format]

Confirm that a Task implementing the Trusted Artifacts pattern declares its workspaces as a list. A present but malformed `spec.workspaces` (for example an object, a scalar or null) would otherwise silently skip the general purpose workspace check.

* Rule type: [rule-type-indicator failure]#FAILURE#
* FAILURE message: `The Task %q defines a malformed spec.workspaces, expecting a list`
* Code: `trusted_artifacts.workspaces_format`
* Effective from: `2026-12-09T00:00:00Z`
* https://github.com/conforma/policy/blob/{page-origin-refhash}/policy/task/trusted_artifacts/trusted_artifacts.rego#L70[Source, window="_blank"]
